📘 C++ Strings Practice Set

This repository contains a structured set of 10 C++ problems focused on strings, designed to help learners build a strong foundation in string manipulation and processing.

The problems progress from basic string handling to logic-based operations, making it ideal for beginners moving toward intermediate-level problem solving.

🎯 Objective

This practice set will help you:

Understand string input and output
Perform string traversal and manipulation
Work with characters and ASCII values
Solve common string-based problems
Build a foundation for advanced string algorithms
📊 Difficulty Level

Covers essential operations and introduces logic-based string problems.

📂 Problem List
🟢 Level 1: Basics
Input & Output String
Take a string as input and print it.
String Length (Without Built-in)
Find the length of a string manually.
🟢 Level 2: Basic Operations
Count Vowels
Count the number of vowels in a string.
Reverse String
Reverse the given string.
🟡 Level 3: Character Logic
Palindrome Check
Check whether a string is a palindrome.
Count Words
Count the number of words in a sentence.
🟡 Level 4: String Manipulation
Convert to Uppercase
Convert all lowercase characters to uppercase.
Remove Spaces
Remove all spaces from the string.
🔵 Level 5: Logic Building
Character Frequency
Count the frequency of each character.
First Non-Repeating Character
Find the first character that does not repeat.

📌 Key Concepts
String traversal using loops
Character handling and ASCII values
Manual implementation of string operations
Basic string algorithms

🚀 Learning Outcome

After completing this set, you will:

Be comfortable working with strings in C++
Understand how to manipulate and analyze text data
Be ready to move to:
Advanced string algorithms
Pattern matching (KMP, Rabin-Karp)
String hashing

✨ Mastering strings is essential for solving real-world text processing and algorithmic problems.
